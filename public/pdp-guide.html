상세페이지 마법사 3.1 시작 안내

도구 이용료, AI API 비용, 강의 수강료는 별개입니다. ChatGPT·Gemini 채팅 구독은 API 결제 수단이 아닙니다. Higgsfield는 연결한 계정의 크레딧을 사용합니다.

처음 시작하기

  1. API 키 설정에서 Gemini 또는 OpenAI 키를 저장하고 사용할 공급자를 고릅니다. Higgsfield는 계정 연결과 제품 분석용 API 키가 하나 필요합니다.
  2. 자료 등록에 제품 이미지·기존 상세페이지·PDF를 넣습니다. 파일별 삭제와 대표 선택으로 사용할 참조를 정리합니다. 상품명, 확인된 특징과 금지 표현을 추가 정보에 적습니다.
  3. 생성 설정에서 공급자·비율·출력 방식을 선택합니다. OpenAI는 Sunburst/Flare와 품질을 고를 수 있습니다. 먼저 첫 장만 생성합니다.
  4. 편집기에서 StoryBrand / 구매 전 고민 해소 / 사용 시나리오 / 비교·근거 강화 구성을 선택하고 구성안 적용 · 문구 확인을 누릅니다. 이 구성·문구 편집은 무료이며 이미지를 자동 생성하지 않습니다.
  5. 이미지 옵션에서 목적·헤드라인·문구, 이미지에서 바꿀 것과 유지할 것을 확인한 뒤 미생성 이미지를 생성합니다. 전체 생성은 최대 2장을 동시에 처리합니다.
  6. 완료된 장은 즉시 표시되고 자동 저장됩니다. 실패한 장만 다시 만들거나 일시정지할 수 있습니다. 응답 확인 필요 장은 공급자 사용량과 결과를 확인한 후 수동으로 다시 생성하세요.
  7. 제품 형태·색상·수치·문구를 검수한 뒤 현재 장 또는 ZIP으로 다운로드합니다. 출력 폭은 1080px입니다.

제품과 문구 수정

원본 제품 사진 고정은 참조 사진을 그대로 올려 제품 픽셀의 재생성을 피합니다. 이동·크기 조절은 캔버스에서 가능합니다. 제품만 고정하려면 투명 배경 제품컷을 대표 자료로 등록하세요. AI 결과 전체의 제품 동일성을 보장하는 기능은 아니므로 원본/결과 비교가 필요합니다.

텍스트편집 모드는 이미지와 별도로 생성된 텍스트 레이어를 직접 수정합니다. 텍스트 수정 자체에는 이미지 API 요청이 없습니다. 통이미지 모드의 글자는 이미지 안에 있으므로 문구 변경 후 재생성해야 합니다. 수정 성공 시 이전 이미지를 보관하며 실패하면 기존 결과를 유지합니다.

후기 원문이 없으면 실제 후기·별점·작성자를 만들어 사용하지 않습니다. 구성안은 구매 전 확인 항목으로 대신합니다. 사전 지식 업로드 기능은 3.1에서 삭제되었습니다.

비용과 오류 해결

이미지 옵션의 생성 비용 확인에서 공급자·모델·품질·누락 장수·요청 횟수를 확인합니다. Gemini 1K 이미지 출력은 장당 $0.067이며 입력·분석·인물 검증은 별도입니다. OpenAI Image 2.5는 품질·크기·입력에 따라 토큰으로 과금되므로 고정 장당 가격을 표시하지 않습니다. 공식 가격과 실제 사용량의 장당 최소/최대값을 입력하면 총 예상 범위를 계산할 수 있습니다. 실제 청구액으로 표시되는 값은 아닙니다. 가격 확인일: 2026-10-05.

  • 잘못된 키: API 키 설정에서 앞뒤 공백을 제거하고 다시 검사합니다.
  • 모델 접근 불가: 선택한 모델의 프로젝트 권한을 확인하거나 접근 가능한 공급자로 변경합니다.
  • API 잔액 부족: 공급자 결제·프로젝트 예산을 확인합니다. 채팅 구독을 추가 구매하는 절차가 아닙니다.
  • 호출 속도 제한: 전체 생성을 일시정지하고 잠시 후 실패한 장만 다시 생성합니다.
  • 시간 초과/응답 확인 필요: 공급자에서 이미 처리되어 과금됐을 수 있습니다. 자동 재시도하지 않으니 사용량과 결과를 확인하세요. 일시정지는 새 요청 시작만 막고 이미 시작된 요청을 환불·취소하지 않습니다.
  • 용량 초과: 자료별 삭제로 전체 첨부량을 줄이거나 작은 참조 이미지로 교체합니다. PDF는 표시된 반영 페이지·텍스트 범위를 확인하세요.

공급자 공식 안내: OpenAI 이미지 생성 · Gemini API 가격

기존 작업·백업

3.0의 같은 브라우저 IndexedDB 작업을 이어서 열 수 있습니다. 작업 백업으로 이미지·문구·설정·편집 레이어를 JSON으로 내보내고 백업 가져오기로 새 작업을 만듭니다. API 키는 백업에 포함되지 않습니다. 브라우저 데이터를 지우기 전에 백업하세요. 1.5/2.0 작업의 자동 이식은 확인되지 않았으므로 기존 폴더와 결과물을 보관하세요.

소스·사용 범위·강의

공식 다운로드 링크, 재배포·수정 이용권, 강의 수강료는 운영자가 제공하는 배포·수강 안내를 확인하세요. 이 로컬 버전은 별도 공개 링크나 이용권을 임의로 약속하지 않습니다. 설치는 받은 프로젝트 폴더에서 pnpm install, pnpm dev를 실행하고 http://127.0.0.1:3002/pdp-maker를 엽니다.
